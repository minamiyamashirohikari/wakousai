実施状況を更新する

このサイトは status.txt というファイルから実施状況を読み取っています。
下のボタンからGitHubを開き、1行目の「区分:」の右側を書き換えると公開ページに反映されます。

GitHubで status.txt を編集する

ワンタップで開けるようにするには： js/config.js の GITHUB_EDIT_URL に、ご自身のリポジトリのURLを 1行書き入れてください（形式：https://github.com/ユーザー名/リポジトリ名/edit/main/status.txt）。 未設定でもサイトは正常に動きます。

「区分:」に書く言葉

  • 通常開催予定どおりすべて実施
  • ステージ中止ステージのみ中止・飲食販売は開催
  • 全体中止警報発令などですべて中止
  • 開催前当日を迎える前の表示
  • 終了閉幕後の表示

GitHubでの操作手順

  1. 上のボタンを押してGitHubを開く（ログインが必要です）
  2. 1行目の 区分: 開催前 の「開催前」を書き換える
  3. 右上の緑のボタン Commit changes を押す
  4. もう一度 Commit changes を押して確定
  5. 1〜2分待ってから「反映を確認する」を押す

見出しと本文を空欄にしておけば、区分に合った文章が自動で表示されます。
# で始まる行はメモ扱いです。消さずに残してください。
