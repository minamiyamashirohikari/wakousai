# Googleスプレッドシート方式

GitHubの`status.txt`の代わりに、Googleスプレッドシートから開催状況を読み取る任意方式です。

## 設定

1. Googleスプレッドシートに`開催状況`というシートを作る。
2. 次の縦型表を作る。

| A列 | B列 |
| --- | --- |
| 区分 | 開催前 |
| 見出し |  |
| 本文 |  |
| 担当者 | 和光祭実行委員会 |
| 更新日時 |  |

3. CSVとして読み取れる共有／公開設定にする。個人情報は入れない。
4. `js/config.js`の`SHEET_ID`に、スプレッドシートURLの`/d/`と`/edit`の間のIDを記入する。
5. `SHEET_NAME`は`開催状況`のままにする。

`SHEET_ID`または`CSV_URL`が設定されると、`MODE: 'auto'`でも自動的にスプレッドシート方式になります。

## 対応する区分

- `開催前`
- `通常開催`
- `ステージ中止`
- `全体中止`
- `終了`

表記ゆれにも対応していますが、上記の言葉をそのまま使うのが安全です。見出しと本文が空欄なら、区分ごとの定型文が表示されます。

## 注意

- サイトからシートを読み取れる公開範囲が必要です。
- シートのURLや内容を公開してよいか、組織の情報管理ルールを確認してください。
- 更新後は公開ページの「最新の状況を再読み込み」で表示を確認してください。
