社会福祉法人 南山城学園「和光祭」の告知用ランディングページです。
**当日の開催状況（通常開催／ステージイベント中止・飲食販売のみ開催／警報発令による全体中止）をリアルタイムにお知らせする機能**をメインに据えています。

## 1. プロジェクトの目的

- 来場を検討している方が、**来場前にスマートフォンで実施状況を確認できる**ようにする
- チラシ・掲示物のQRコードから直接アクセスできる導線をつくる
- 職員（支援員）が専門知識なしに、その場で実施状況を切り替えられるようにする

## 3. 実装済みの機能

### ✅ 3つの運用方式に自動対応

開催状況の読み取り先は、**サイトの置き場所（ホスト名）から自動判定**されます（`MODE: 'auto'`）。

| 置き場所 | 判定 | 読み取り先 | 更新方法 |
| --- | --- | --- | --- |
| `*.gensparksite.com` など | `genspark` | Table API / D1 | `admin.html` の入力フォーム |
| `*.pages.dev` / `*.github.io` / 独自ドメイン | `file` | **`status.txt`** | GitHubでファイルを書き換え |
| シートIDを記入した場合 | `sheet` | Googleスプレッドシート | シートのセルを書き換え |

`js/config.js` の `MODE` を `'file'` / `'sheet'` / `'genspark'` と明示すれば、自動判定を上書きできます。

静的ホスティング（`file` / `sheet`）のときはサイトからの書き込みができないため、
`admin.html` の表示も自動で**「編集先を開くボタン＋書き方の早見表＋操作手順」**に切り替わります。

### ✅ `status.txt` による更新（GitHub運用）

リポジトリ直下の `status.txt` を書き換えるだけで表示が切り替わります。

```
区分: 開催前
見出し:
本文:
担当者: 和光祭実行委員会
更新日時:
```

- `通常開催` / `ステージ中止` / `全体中止` / `開催前` / `終了` と日本語で書くだけ
- 「警報で中止」「飲食販売のみ開催」のような表記ゆれも自動判定
- 全角コロン「：」でも読み取り可
- 見出し・本文を空欄にすると、区分に合った文章を自動表示
- `#` で始まる行はコメント（ファイル内に使い方を記載済み）
- キャッシュ回避処理入りのため、更新後の内容を確実に読みます

### ✅ スプレッドシートによる更新

シートにも同じ言葉を書くだけで判定されます。
「縦型（A列＝項目名）」と「横型（1行目＝見出し）」のいずれの表の作り方でも読み取れます。

### ✅ 開催状況のお知らせ機能（メイン機能）

公開ページ上部の「当日の開催状況」カードに、最新の実施状況が表示されます。区分に応じてカードの色・見出し・本文が自動的に切り替わります。

| 区分（status_code） | 表示 | カラー |
| --- | --- | --- |
| `before` | 開催前・準備中 | ブルー |
| `open` | 通常開催 | グリーン |
| `stage_cancel` | **ステージイベント中止（飲食販売のみ開催）** | イエロー |
| `cancel` | **全体中止（警報発令など）** | ピンク／レッド |
| `ended` | 終了しました | グレー |

- 最新の1件（発表日時が最も新しいレコード）を自動で採用
- **5分ごとに自動再取得**／タブに戻ったときも再取得／手動の「再読み込み」ボタンあり
- 画面下部に**追従バナー**を表示し、どこを見ていても現在の状況が分かる
- `aria-live="polite"` により、スクリーンリーダー利用者にも更新が伝わります

### ✅ 職員用ページのパスコードロック

- `admin.html` を開くと、まず**4桁のパスコード入力画面**が表示されます
- **現在のパスコード：`1456`**
- 正しく入力するまで更新フォームは表示されず、データの読み込みも行われません
- 「この端末では次回から入力を省略する」にチェックすると、その端末では次回以降入力なしで開けます（チェックしない場合はブラウザを閉じるまで有効）
- 5回連続で間違えると1分間入力できなくなります（総当たり対策）
- 画面下部の「ロックする（ログアウト）」ボタンで、いつでも入力画面に戻せます

> **パスコードの変更方法**：`js/auth.js` の 1 行目付近にある `var PASSCODE = '1456';` の数字を書き換えてください。

> ⚠️ これはブラウザ側で判定する簡易ロックです。**関係者以外の誤操作を防ぐ**ことを目的としており、技術的な知識がある第三者に対する強固な保護ではありません。より確実に保護したい場合は、下記「今後の検討事項」のアクセスルール設定をご検討ください。

### ✅ 職員用 実施状況 更新画面（`admin.html`）

- **定型文ボタン**（○通常開催／△ステージ中止・飲食のみ／×警報で全体中止／準備中／終了）を押すだけで、見出しと本文が自動入力されます
- 文章はその場で自由に編集可能
- 公開前に確認ダイアログを表示（誤操作防止）
- 「いま公開されている内容」を実際の公開ページと同じ見た目でプレビュー
- **更新履歴**（最新10件）を一覧表示

### ✅ 印刷物用QRコード固定機能

- ページ最下部の「QRコードでこのページへ」セクションでは、印刷物用の固定PNG（`images/minamiyamashiro-wakousai-qr.png`）をそのまま表示します
- 「QRコード画像を保存」ボタンでも同じ固定PNGをダウンロードします。動的な再生成は行いません
- 「URLをコピー」ボタンでURLをクリップボードへコピー
- 読み取り先URL・画像ファイル・SHA-256は`docs/QR-CODE-LOCK.md`に記録し、年度更新や通常編集では変更禁止としています
- GitHub Actionsでも`scripts/verify-qr-lock.mjs`を自動実行し、固定値の差異を検知します

| メソッド | エンドポイント | 用途 |
| --- | --- | --- |

## 5. データモデル

### テーブル: `status_updates`

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `id` | text | レコードID（自動採番） |
| `status_code` | text | 開催状況コード（`before` / `open` / `stage_cancel` / `cancel` / `ended`） |
| `headline` | text | 見出し（大きく表示） |
| `detail` | rich_text | 来場者へのご案内本文（改行が段落になります） |
| `updated_by` | text | 更新担当者・発表者名 |
| `published_at` | datetime | 発表日時 |

※ 更新は「上書き」ではなく**追記方式**です。過去の発表内容が履歴として残り、常に最新の1件が公開されます。

**ストレージ**：Genspark RESTful Table API（プレビュー環境は CosmosDB、ホスティング環境は Cloudflare D1）

### ⚠️ プレビュー環境と公開環境のデータは別管理です

エディタ内のプレビューと、公開サイト（Cloudflare）のデータベースは**別の場所に保存**されます。
当日の更新は必ず**公開URLの `/admin.html`** から行ってください（エディタのプレビューで更新しても、来場者には反映されません）。

公開環境には初期データとして「開催前・準備中」のレコードを投入済みです。

## 6. 職員向け 当日の運用手順

1. 当日朝（判断目安 **8:30**）に公開URLの `/admin.html` をスマートフォンで開く（ブックマーク・ホーム画面への追加推奨）
2. **パスコード `1456`** を入力して「ロックを解除する」を押す
3. 状況に合うボタンを押す
   - 晴れ・予定どおり → **「○ 通常開催」**
   - 雨だがステージだけ中止 → **「△ ステージ中止・飲食のみ」**
   - 警報発令などで全体中止 → **「× 警報で全体中止」**
4. 必要なら文章を修正（例：具体的な警報名、再開の見込みなど）
5. 「この内容で公開する」→ 確認ダイアログで「OK」
6. `index.html` を開いて、表示が切り替わったことを確認

> 開催中に天候が変わった場合も、同じ手順で何度でも更新できます。

## 7. 未実装／今後の検討事項

- **管理画面の本格的なアクセス制限**：現状は4桁パスコードによる簡易ロックです。より確実に保護する場合は、ホスティング公開後に Hosted のアクセスルール（職員メールアドレスの許可リスト等）を設定することを推奨します。
- **プッシュ通知・メール配信**：状況が変わった際の能動的な通知は未実装です（現状は来場者側の確認が前提）。
- **既存レコードの編集・削除UI**：現在は追記のみで、過去の履歴を管理画面から修正・削除する機能はありません。
- **会場マップ画像**：チラシにある地図は未掲載です（Googleマップリンクで代替）。掲載可能な画像をいただければ差し替えます。
- **多言語対応（やさしい日本語・英語）**：未対応です。
- **写真素材**：現在は昨年度チラシ画像のみを使用しています。当日の写真や各出店の写真があれば差し替え可能です。
